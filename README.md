# Fiscalizá · Fiscalización electoral 2027

Propuesta de una aplicación web instalable en el celular para organizar la fiscalización electoral en la provincia de Buenos Aires: de la provincia a la mesa.

**Ver la página:** https://monkeyhorde-cloud.github.io/fiscaliza.pba/

## Contenido

| Archivo | Qué es |
|---|---|
| `index.html` | Página de inicio |
| `Fiscaliza-Presentacion-v3.html` | Presentación de la propuesta (15 diapositivas) |
| `Fiscaliza-Animacion-v4.html` | Animación: del mapa a la mesa y del papel al dato |
| `preview.jpg`, `miniatura-*.jpg`, `icono.png`, `favicon.png` | Imágenes de la página |

Los archivos funcionan sin conexión: se pueden descargar y abrir directamente en el navegador.

## Cómo usarlos

- **Presentación:** flechas o clic para avanzar; `F` pantalla completa. En el celular, tocá a la derecha para avanzar.
- **Animación:** `Espacio` para comenzar o pausar; flechas para saltar de escena. En el celular, tocá para comenzar.

## Aclaración

Las escuelas, mesas y resultados que aparecen son **datos ilustrativos**, usados solo como ejemplo. El mapa muestra los límites reales de los partidos bonaerenses.
